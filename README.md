## 三条偏好

1. **本地优先** — 能离线就不联网，数据能自己拿着就自己拿着。
2. **能自托管就自托管** — 域名、部署、备份、监控，尽量不让别人替我保管。
3. **AI 结对，人拍板** — 让 AI 写样板、查边界、补测试；架构和取舍自己负责。
